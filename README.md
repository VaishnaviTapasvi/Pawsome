# 🐾 Pawsome – Pet Shop & Management System

A complete PHP-based web application that allows users to browse pets, purchase dogs, and enables admins to manage listings and user details.
This project combines:
✔ Pet E-Commerce / Shop
✔ Pet Management Dashboard (Admin Panel)

### 🚀 Features  
#### 👤 User Features  
- Browse pets by breed (Beagle, Husky, Doberman, Pug, etc.)  
- View pet details  
- Add pet to cart (shopping functionality)  
- Fill undertaking form  
- User login & authentication  
- Checkout page with billing details  

#### 🛒 Cart / Purchase Features  
- Store cart data in MySQL

#### 🐶 Admin Features  
- Admin login & authentication  
- Add pets by breed  
- Upload pet images  
- Manage uploaded pets  
- Approve adoption requests  
- Manage users  

#### 🛠️ Tech Stack  
- Frontend: HTML, CSS  
- Backend: PHP  
- Database: MySQL  
- Server: XAMPP / WAMP / LAMP  

#### 🖥️ How to Run the Project Locally  
1. Install XAMPP  
Download XAMPP from Apache Friends  
Start:
- Apache  
- MySQL  

2. Move the Project  
Copy the project folder to:  
C:/xampp/htdocs/pawsome  

3. Import the Database  
Open phpMyAdmin  
Create a new database (example: pawsome)  
Import:
- user.sql  
- addtocart.sql  

4. Run the Website  
Open browser:  
http://localhost:3000/Homepage.php  


#### 📸 Images  
- All pet images are stored in /images.   
- Ensure database stores only the filename, not the full path.
